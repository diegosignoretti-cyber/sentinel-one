# Esempi — caso dimostrativo

**Tutto il contenuto di questa cartella è interamente fittizio.** Azienda
("Meridiana Componenti S.p.A."), persone, fornitori, domini, email e importi sono
inventati e servono solo a mostrare al board il **formato finito** di un dossier.

| File | Contenuto |
|---|---|
| [`dossier-esempio-completo.html`](dossier-esempio-completo.html) | I 4 dossier compilati (CEO, CFO, Acquisti, HR), un foglio A4 ciascuno |

Ogni foglio riporta la filigrana `CASO DIMOSTRATIVO — DATI FITTIZI` e una barra
rossa in testata, così non può essere scambiato per un dossier reale.

## Uso

Aprire il file nel browser → *Stampa* (cartoncino 120–160 g) oppure *Salva come PDF*.
Per i dossier reali: partire da `../templates/dossier-one-pager.html` e compilare
con le evidenze raccolte dall'auditor interno.
